# 实验 3 网页地面站：地图、无人机符号与米制遥测专项审查

日期：2026-10-31

## 本次范围

仅调整实验 3 的地图显示、飞机符号和支撑其一致性的模拟遥测；不更改实验 1、实验 2，不调整步骤 5 教学入口、独立指挥台的页面结构和业务配置。

- `src/domain/collaborationBasemap.ts`：实验 3 独立维护 MapLibre 二维样式；卫星源与实验 2 一致，但没有导入实验 2 的地图组件/配置。增加默认二维矢量模式，保留卫星、纯 ENU 坐标模式。
- `components/FleetMap.tsx`、`FleetMap.module.css`：采用实验 2 同款四旋翼 SVG，移除卡片式地图标记；固定屏幕尺寸，符号中心严格锚定遥测位置。编号、状态点、航向指示独立绘制，不撑开定位边界。新增选中飞机到最近邻的实时水平距离标注。
- `TaskCommand.module.css`：仅删除覆盖地图飞机为方形卡片的样式，不改任务面板和平台布局。
- `CollaborationMockRuntime.ts`、store、类型：默认 3×5 阵列行列间距均为 5m；200ms 更新，同一份位置样本生成速度、姿态、航向、电量和轨迹。
- 遥测面板：显示实际地速/垂速，而不是用机型巡航能力充当实时速度。轨迹附时间戳，响应时间不再错误地按原 850ms 采样周期计算。

## 第一轮：实现/数据审查

发现旧实现的问题：

1. 原始卫星影像过度放大，只能变大，无法增加地物细节。
2. 同款四旋翼 SVG 被指挥台 CSS 套成方形卡片，编号参与布局，影响观感。
3. 原机位间距为 24m/28m，并非 5m；运动按固定大步长推进，速度字段实际上是巡航能力。

处理：

- 默认使用真实在线二维矢量几何，并保留同源卫星作为参照；没有用截图或虚构地物作底图。
- 地图、航线、轨迹、点位、比例尺共用一个 ENU/WGS84 投影和相机。
- 默认每行/列相邻机位 5m，当前近邻距离由坐标计算，不硬编码“5m”标签，也不把重合飞机强行挪开。
- 运动按时间积分，水平巡航限速、加速上限、垂直起飞；RTL 先飞回各自 Home，再下降并释放资源。暂停悬停速度归零但仍耗电；返航不受任务暂停影响。

## 第二轮：桌面视觉与真实瓦片审查

使用真实 Chrome/MapLibre，检查 2048×1152、1600×1000、1366×768：

- 矢量底图真实加载成功，非本地占位图；卫星瓦片真实加载成功。
- 无人机保持 32px 定位边界、30px 四旋翼图形；编号不改变符号中心，航向由遥测 yaw 驱动。
- 初始 5m 近邻距离与米制比例尺一致，屏幕坐标独立反投影误差小于 1px。
- 自动适配、拖动、缩放、任意非阵列坐标注入后仍保持配准。
- 航线、轨迹及航点改为固定屏幕线宽/尺寸，避免放大后变成粗线块。
- 以桌面全宽截图验收，不采用窄图代表地面站效果。

## 第三轮：行为、降级与回归审查

- 测试真实等待爬升结束及水平移动，再核对地图轨迹、地速、高度、电量；不是只用起飞前的静态画面验收。
- 起飞 → 执行 → 暂停 → 继续 → 单机 RTL → 安全落地/终止，使用同一运行状态源。
- 矢量和卫星分别阻断网络：仍显示米制网格、飞机及点位，保留任务操作；错误提示可重试或切换坐标模式。
- 指挥台 → 教学入口 → 再打开、左侧面板收展、实时视图与任务视图切换均检查。
- 桌面优先，同时检查 390px 手机兼容；手机不是主要设计验收视口。

## 交付限制

1. 在线地图明确依赖外部瓦片网络；离线可完成坐标图层上的核心任务，但不是已经交付离线地理瓦片包。
2. 矢量图放大后几何边缘保持清晰，不意味着地物数据具备测绘级精度。卫星模式也不会因放大获得额外分辨率。
3. 实时状态是教学运动学模拟，不是实机遥测、真实飞控动力学或经过认证的避碰系统。5m 是默认初始机位间距及任务编队目标间距；飞行中显示实际距离，不保证所有飞机始终刚性相隔 5m。
4. 未更改实验 2 的实现；以后实验 2 修改地图/图标不会自动改变实验 3。
