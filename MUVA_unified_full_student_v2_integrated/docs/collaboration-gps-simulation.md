# 实验三 GPS 欺骗教学模拟

实验三当前由 Service Registry 注入 `CollaborationMockRuntime`，无需连接无人机或后端。

## 操作

1. 启动模拟集群并部署、运行一个或多个任务。
2. 在攻击面板点击 GPS 欺骗，在同一弹窗跨任务勾选目标。顶部“编辑无人机”切换当前飞机，分别设置东/北/高度偏移、静态/渐变/路径模式、强度、噪声、时间与停止边界。“正在配置”始终显示当前飞机，所有参数只修改当前飞机。
   - “复制当前参数到全部已选”会覆盖全部已选飞机的参数，之后可以继续逐机修改。
   - “配置预览”包含逐机对照表；点击飞机编号可以返回该机的位置设置。
   - 切换飞机或临时取消勾选不会丢失本次编辑。保存只保留已选飞机，重新打开或刷新后仍保留各机配置。
   - 保存时检查全部已选飞机；任一飞机参数无效会阻止保存，并切换到该机提示。
3. 点击“启动 GPS 欺骗”。目标可跨任务选择，可全选，数量受当前资源池限制，没有额外攻击数量上限。
4. 可继续配置其他目标并启动另一批攻击；同一架飞机已有攻击时整批启动请求会被拒绝，需先停止该机攻击。
5. 活跃攻击区支持逐机停止和全部停止。保存配置不会自动执行，编辑预设不会修改已启动攻击的配置副本。

## 仿真含义

- `Drone.position` 是真实模拟位置。GPS 观测 = 真实位置 + 欺骗偏移。
- 飞行控制用受欺骗的定位计算目标误差，并通过现有运动学模型移动真实飞机。正东的假定位偏移可能引发向西的实际修正运动。
- 不修改计划航点、Home 或地图原点，不在地图组件里伪造位置。五类任务共用同一执行链路。
- GPS 定位以橙色空心点显示，虚线连接真实位置；选中飞机显示水平偏移及高度偏移。
- 受攻击期间实际轨迹以红线显示。停止后新航迹恢复普通颜色，历史红段及归档任务记录保留。
- 地面接力/救援队列仍等待原任务依赖才起飞。任务暂停冻结任务运动，但攻击计时继续；待人工确认时仍按受影响定位悬停。
- 返航/任务退出会清除该机攻击；批次标识避免攻击延续到下一次任务。停止后由飞行模型逐步回到正常航线，不会瞬移。

## 参数语义与范围

- 每架飞机独立支持静态、渐变、路径模式；线性/平滑插值；固定种子噪声。延迟、持续时间、强度、停止条件均逐机执行，同一批次可以不同时间开始或结束。
- 旧版共享参数预设继续兼容。每架飞机启动时取得独立配置快照，修改预设不会影响运行中的攻击。
- 强度按 35% / 65% / 100% 缩放偏移和噪声。
- 非循环路径在持续时间内遍历一次；循环路径每段 10 秒。
- 支持延迟、持续时间、更新间隔。更新间隔低于 200 ms 时按遥测周期 200 ms 执行。
- 最大水平偏移约束偏移向量；高度上下限约束生成的定位偏移。启用围栏时还约束偏移幅度；开启越界停止时，真实位置超出以 Home 为圆心的围栏或高度范围会终止攻击。
- 断连策略可停止、冻结该机攻击计时并恢复正常定位、继续。任务本身的故障返航优先。
- 参考经纬度、高度仅作预设备注；日志级别、记录开关保留配置，尚不控制运行器。任务轨迹始终保留以支持红色航迹复盘。
- 其余基础攻击和组合脚本仍属于配置/预览功能，此次只接入 GPS 执行。

## 验证

- `npm run test:collaboration-gps`：并发五类任务、真实运动与定位分离、任意目标数、分批攻击、隔离、延迟/到期、插值/噪声、断连、任务退出/归档、队列依赖与悬停恢复。
- `npm run test:collaboration-gps-browser`：通过 UI 部署五类并发任务，选择 15 架目标，为不同任务的飞机设置不同偏移/延迟，启动、核对逐机执行参数、查看红线/GPS点、逐机停止和全部停止。
- 浏览器脚本使用 `MUVA_TEST_URL`（默认端口 5188）、`PLAYWRIGHT_CORE_PATH`、`CHROMIUM_PATH` 配置运行环境。

- `npm run test:attack-config` 和配置/目标浏览器测试：逐机解析与验证、旧预设兼容、独立编辑和复制、隐藏目标错误定位、本地保存恢复、桌面与窄屏布局、与攻击库相同尺寸。
