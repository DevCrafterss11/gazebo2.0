# 实验三：学生操作流程审查与修正（2026-10-31）

本轮在现有实验三上迭代，未接入真实飞控，未改动实验一、实验二业务代码，未提交或推送代码。用户已有文档、未跟踪文件及 dump 文件保留。

## 审查结论

原有实现已经具备六步教学导航、15 架独立无人机与树莓派映射、统一运行时、五类独立任务、地图绘制、资源配置、单机返航和历史记录。这些能力继续复用。

本轮实际修复的是学生操作中断、状态边界和地图可操作性问题，而非重新搭建系统。当前业务为一个资源池、五种独立任务入口、一次执行一个任务；一个任务可包含多架无人机。

| 原有问题 | 本轮处理 |
|---|---|
| 1366×768 下指挥台底部开始、绘制和控制操作超出教学视口 | 第五步采用可伸缩高度，删除重复外层底部导航，调整短屏浮层高度；窄屏可滚动到完整操作栏 |
| 尚未开放任务资格时，学生面对一排不可选无人机，缺少就近操作 | 编组图层提供明确的资格开放入口；只开放当前类型资格，不自动加入任务、不占用资源、不起飞 |
| 参数、绘制、编组之间缺少连续指引 | 参数图层提供绘制和编组入口；开始检查失败自动打开对应图层 |
| 取消确认仍停留在待确认状态，开始结果缺少明确反馈 | 取消回到配置中；准备和开始动作均返回是否成功，未确认不能执行 |
| 关键角色或双机确认成员返航后，资源不足仍可能继续 | 按任务最低资源数和关键角色检查，进入异常处置；资源不足阻止继续，提示终止后重新编组 |
| 区域、参数和角色存在漏校验 | 校验高度等数值范围、区域面积与自交/重复点、主角色、双机确认数量和资源资格 |
| 定点监测可累积多个点，但运行时只使用一个 | 明确单点监测；再次设置替换原点，地图、参数和执行保持一致 |
| 返航落地释放占用后，任务地图的单机轨迹可能消失 | 轨迹按已执行任务成员保留，独立于当前占用关系 |
| 历史任务详情显示当前实时遥测，并可能提供当前返航操作 | 历史详情读取归档快照，标记历史只读，取消历史视图中的飞行控制 |
| 重叠图标遮挡鼠标，返航面板操作不可靠 | 对重叠标记做屏幕位置避让，用细引线连接实际坐标；遥测坐标不变 |
| 浮层遮挡初始阵列和定位目标 | 地图适配视野考虑左右浮层与底部工具栏，选中无人机定位到可见区域 |
| 任务结束后可能绕过再次执行流程 | 已结束任务必须通过“再次执行”或新建恢复配置状态，历史记录继续保留 |
| 手动返航导致任务降级，却未计入异常评价 | 记录资源退出告警；评价按实际告警事件计数，说明覆盖率的教学估算口径 |
| 部分高级参数只有保存，没有对应模拟 | 监测、运输参数旁明确提示尚未模拟的时序轮换与自动航线优化，避免误导 |

## 学生操作链路

1. 系统感知：查看真实检查接口未接入说明，主动进入教学模拟模式。
2. 集群启动：启动 15 架实例，进入未解锁待命状态；此时零实际任务分配。
3. 通信组网：查看 15 组一一映射和模拟心跳，明确数据来源为 Mock。
4. 集群状态监控：列表与地图选择联动，查看独立遥测。
5. 多任务协同指挥：选择任务类型 → 设置专属参数 → 绘制区域/目标/运输起终点 → 开放资源资格 → 勾选成员和角色 → 点击开始 → 确认当前任务。执行中可暂停、继续、独立返航、处置异常或终止；切换页面不丢失当前运行状态。
6. 实验评价：任务完成或终止并完成安全收尾后，读取实际执行记录。任务工作区保留计划路线、实际轨迹、事件和结果，可以再次执行、新建或查看历史。任务结束集群保持运行；停止集群需要确认并等待安全状态。

## 状态与模拟边界

- `enabled`、`allowedTaskTypes`、`visibleOnMap`、`assignedTaskId`、角色和实例状态继续独立管理。草稿成员不会占用资源。
- 现有 Zustand Store 负责动作编排，Service Registry 提供已有 Runtime。未新增页面私有模拟器或额外定时器。
- 现有 Runtime 以 450 ms 更新集群启动/心跳，以 850 ms 推进任务运动；启动幂等，停止和重置清理对应定时器。页面切换保留状态，停止集群为显式操作。
- 暂停冻结任务进度与任务轨迹，心跳继续；单机返航是独立安全过程，暂停期间仍可完成返航落地。
- 五种任务分别采用巡逻扫描/区域路线、搜索扫描/扇形路线、到点驻留、运输航点与交付确认、救援优先级与目标路线。并非统一启动五个任务组。
- 评价读取轨迹、执行计数及事件；覆盖率为轨迹与计划路线采样估算，并非传感器覆盖模型。异常数按告警事件统计，例如低电量与随后关键角色退出是两条告警。
- 运行状态保持范围为当前前端会话内切换页面；不承诺刷新后恢复实时运行。
